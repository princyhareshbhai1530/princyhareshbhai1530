**Efficient LLM fine-tuning for structured banking-support information extraction**

`PyTorch` · `Qwen2.5-1.5B` · `QLoRA` · `PEFT` · `Transformers` · `FastAPI`

* Fine-tuned **Qwen2.5-1.5B** on synthetic banking-support tickets using QLoRA.
* Applied **4-bit NF4 quantization** for memory-efficient model adaptation.
* Used **completion-only loss masking** to improve training alignment.
* Built a structured experimentation pipeline using Hugging Face PEFT and Transformers.
* Developed a **FastAPI evaluation interface** for comparing base and fine-tuned outputs.

> **Focus:** Efficient fine-tuning · LLM evaluation · Financial-services NLP

## 🎙️ Real-Time Voice Agent

**Low-latency conversational AI with interruption handling**

`FastAPI` · `WebSockets` · `Web Audio API` · `SQLite` · `OpenAI Streaming APIs`

* Built a real-time **speech-to-speech AI agent**.
* Designed finite-state-machine based conversational turn handling.
* Implemented **barge-in interruption support** for natural user interactions.
* Streamed **20 ms PCM16 audio frames** through ASR → LLM → TTS components.
* Designed the pipeline around an **800 ms latency budget**.
* Added per-turn latency instrumentation and live monitoring.

> **Focus:** Voice AI · Streaming systems · Conversational agents
